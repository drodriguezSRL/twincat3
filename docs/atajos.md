## Anexo A — Resumen de atajos de teclado en TwinCAT XAE

| Acción | Atajo |
|---|---|
| Compilar solución | `Ctrl + Shift + B` |
| Login al PLC | `Alt + F8` |
| Arrancar ejecución | `F5` |
| Parar ejecución | `Shift + F5` |
| Write variable | `Ctrl + F7` |
| Force variable | `F7` |
| Toggle Breakpoint | `F9` |
| Step Over | `F10` |
| Logout del PLC | `Alt + F8` (de nuevo) |
