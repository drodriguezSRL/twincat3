Referencias y recursos adicionales

Documentación oficial

  • Beckhoff Information System (referencia completa de TwinCAT 3):
    https://infosys.beckhoff.com
    → Sección: TwinCAT 3 → PLC → Sequential Function Chart (SFC)

  • Descarga gratuita de TwinCAT 3 XAE:
    https://www.beckhoff.com/twincat3

Estándar de referencia

  • IEC 61131-3: Programmable controllers — Part 3: Programming languages.
    Define los cinco lenguajes PLC incluyendo el SFC. Disponible en la web de la IEC o a través de AENOR en España.

Recursos de aprendizaje complementarios

  • RealPars — Tutoriales de SFC y PLC en inglés:
    https://www.realpars.com

  • Canal oficial de Beckhoff en YouTube: busca "SFC programming TwinCAT" para encontrar la serie de vídeos oficiales de introducción.

  • infoPLC — Comunidad hispanohablante de automatización:
    https://www.infoplc.net
